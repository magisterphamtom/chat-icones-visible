# Chat — icônes toujours visibles

Module Foundry VTT v14 (tous systèmes, testé pour D&D 5e).

## Le problème
Sous le chat, la rangée d'icônes (modes de message, enregistrer le chat, vider le chat, et celles que d'autres modules ajoutent) ne passe jamais à la ligne : quand il y en a trop, les dernières sortent du cadre et sont inaccessibles.

## Ce que fait le module
Les icônes passent à la ligne suivante quand la place manque. Rien d'autre n'est modifié. Les icônes ajoutées par tes futurs modules sont prises en compte automatiquement.

## Réglage
« Icônes du chat à la ligne » (Configuration → Paramètres des modules), activé par défaut, propre à chaque joueur.

## Installation
Lien du manifeste : `https://github.com/magisterphamtom/chat-icones-visible/releases/latest/download/module.json`
